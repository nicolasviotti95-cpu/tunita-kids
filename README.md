# Tunita Kids

Sitio estático para **Tunita Kids**, tienda de ropa infantil de Mercedes, Soriano. Incluye la portada y el personaje cactus oficiales compartidos por la tienda.

## Vista local

Abrí `index.html` en un navegador para recorrer la página.

## Publicar con GitHub Pages

1. Subí el contenido de esta carpeta a un repositorio de GitHub.
2. En el repositorio, abrí **Settings → Pages**.
3. En **Build and deployment**, elegí **Deploy from a branch**.
4. Seleccioná la rama principal y la carpeta `/ (root)` y guardá.

El sitio usa rutas relativas para que funcione en GitHub Pages. La portada usa los recursos oficiales de Tunita Kids. El catálogo se podrá completar con prendas y precios cuando estén definidos.
